# Orchestra

Orchestra is a self-contained .NET 10 CLI, `orchestrate`, for installing
portable personal defaults, project adapters, subagent definitions, and skills
for evidence-driven debugging, feature delivery, and project-harness
bootstrapping across Codex, Claude Code, and Cursor. The public repository is
available for developing or auditing the harness.

See [INSTALL.md](INSTALL.md) for setup, updates, project adoption, model
assignments, work/personal boundaries, and safe uninstall instructions.

See [delegation evaluation](docs/delegation-evaluation.md) for the quality,
completion-speed, and token targets and the executable coding evals.
